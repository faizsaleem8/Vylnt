# VYNLT model qualification follow-up (ML-Q)

Status: **open**, separate from experimental M6, which the user closed on 2026-10-22. Independent human review is not required for the current controlled phase; preserve controlled provenance. No category is validated. The current display-only runtime cannot hide observations, change severity or turn a score into a harmless verdict.

- [ ] Expand genuinely distinguishable controlled evidence and application-family coverage. Repeated harness targets do not establish independent security situations. Preserve actual family IDs and shared-input components; audit duplicate/conflicting contexts and abstain when scanner evidence cannot distinguish intent.
- [ ] Freeze a new dataset/split and preregister a candidate before fitting/evaluation. Never optimise against the expanded candidate's consumed test. Fit on training only; select checkpoint/calibration/two decision thresholds on validation only. Use the same inputs/partitions for LSTM and logistic comparisons.
- [ ] Meet each category's original gates: at least ten held-out application families overall; at least 30 change-required and 30 contextual test examples per approved category, each class across at least three families; precision >=90%, recall >=95%, non-abstention coverage >=50%; no high/critical actionable example contextual; precision improves over rule-only with recall no more than five percentage points lower.
- [ ] Publish raw and safeguarded category metrics, contextual/insufficient-evidence mistakes, uncertainty intervals, scope, comparator results and failed experiments. Evaluate each frozen release test once. Controlled measurements support only that controlled suite, not universal real-application accuracy.
- [ ] Only after passing the applicable gates, build and verify an explicitly versioned qualification/release integration with browser/API parity, archived report compatibility and conservative aggregation. Unsupported categories remain Needs review; high/critical findings remain visible.

Latest expanded evaluation has two test families and 32 rows; every category fails count/scope gates and CK-002 recall is zero. It is not releasable for relevance decisions.
